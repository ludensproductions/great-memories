# One-Click [Cloud Service]

:::note
This version of Great Memories is provided via cloud service providers' one-click marketplaces. Hosting costs are set by the cloud service providers.
Support for these are provided by the individual cloud service providers.

**Please report issues to the corresponding [Github Repository][github].**
:::

## Installation

Go to the provider's marketplace and choose Great Memories, then follow the provided instructions.

## One-Click Great Memories marketplace providers

### DigitalOcean

https://marketplace.digitalocean.com/apps/great-memories

### Vultr

https://www.vultr.com/marketplace/apps/great-memories
